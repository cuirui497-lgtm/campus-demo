# 云境 · 智慧校园数字孪生演示

纯前端客户演示，所有数据均为模拟。校园由程序化三维几何构成，不是参考学校的测绘模型。

## 启动

在本目录运行 `python3 -m http.server 8080 --directory dist`，浏览器打开 http://localhost:8080 。需要支持 WebGL 的现代浏览器。Three.js 已保存在本地，无运行时外网依赖。不要直接双击 HTML（ES 模块需要 HTTP 服务）。

## 演示流程

1. 展示校园全景，拖动旋转、滚轮缩放。
2. 点击建筑或左侧空间列表，查看楼层及设备概况。
3. 点击实时事件，演示告警空间定位。
4. 在建筑详情中模拟开关照明。
5. 开启自动巡航，或点击默认视角复位。
6. 右上角可进入全屏。

三维建筑及模拟业务字段位于 dist/app.js，样式位于 dist/style.css。无后端、真实设备连接、真实监控流或持久化控制。
