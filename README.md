# 云境 · 智慧校园数字孪生演示

纯前端客户演示，所有数据均为模拟。校园由程序化三维几何构成，不是参考学校的测绘模型。

## 启动

在本目录运行 `python3 -m http.server 8080 --directory dist`，浏览器打开 http://localhost:8080 。需要支持 WebGL 的现代浏览器。Three.js 已保存在本地，无运行时外网依赖。不要直接双击 HTML（ES 模块需要 HTTP 服务）。

## 演示流程

1. 展示校园全景，拖动旋转、滚轮缩放。
2. 点击建筑或左侧空间列表，查看楼层及设备概况。
3. 点击实时事件，演示告警空间定位。
4. 在建筑详情中模拟开关照明。
5. 开启自动巡航，或点击默认视角复位。
6. 右上角可进入全屏。

三维建筑及模拟业务字段位于 dist/app.js，样式位于 dist/style.css。无后端、真实设备连接、真实监控流或持久化控制。

## 房间、环境与设备联动

演示数据统一包含 128 间房间、386 台设备（其中 2 台为楼栋共享环境传感器），初始 97 间使用中，380 台设备在线。楼层、房间、设备编号和告警关联使用同一套数据。

- 建筑详情支持切换楼层和房间；房间卡片显示使用状态、温度、湿度、AQI、PM2.5 和关联照明、摄像头、门禁。
- 设备页支持全部、在线、离线筛选；在线照明和门禁支持模拟开关。离线设备不可下发控制。
- 环境预警指向教学楼 A 的 301 教室及北区环境传感器；摄像头离线指向图书馆 201 阅览室。
- 点击告警可定位并高亮建筑，场景中的亮点为楼栋级设备位置示意，非室内精确坐标。告警支持确认和模拟恢复，同步更新概览数量、在线率及房间温度。
- 状态仅保存在当前页面会话；刷新还原初始模拟数据。底部“模拟告警”可再次触发温度异常。Esc 可关闭详情。

## 本次验证

已检查数据一致性（房间数、设备唯一编号、在线数、占用数、告警引用），并在浏览器验证楼层房间切换、空闲状态、照明控制、离线筛选、两类告警恢复及在线率同步。

## V2：智能运营 + 客户讲解 + 场景精修

点击底部“一键讲解”，选择“校园日常运行”“环境异常处置”或“设备离线排查”，开始自动分步展示。可暂停、继续、前后切换、跳到指定步骤、手动接管或重置。自动讲解期间操作讲解面板以外的界面，会暂停并交还控制；继续后恢复当前讲解步骤。重置会还原整个模拟会话的设备及告警数据。

告警详情新增采样趋势、阈值/心跳规则、影响范围、规则建议与事件时间线。按“确认告警 → 模拟排查 → 复测并恢复”完成闭环。此流程不接入真实 AI、工单系统或现场设备。恢复前的触发序列作为历史依据保留，复测结果追加到曲线中。

场景加入程序化道路与广场材质、屋顶光伏与机组、斑马线、座椅、景观水面及花池。资源均在本地，无新增运行时网络依赖。楼层展开、房间平面图等 B 方向待客户需求确认后扩展。

验证包含：事件操作顺序与重复操作保护、时间线、两种异常恢复、在线率同步；浏览器检查讲解暂停、跳步、回退、场景切换、手动接管与重置。
